# Activity Manager

## a messaging app that allows you to add friends create groups and chat with other people.

frontend created using:
Vite, react, html, tailwindcss, typescript,

backend created using:
NodeJs, express, prisma, jest, typescript, socket.io, multer, aws-s3

Visit the site here: https://activity-manager-frontend.vercel.app/
and Register. (Note that because the app is uploaded on render with a free plan the initial load might be slow and you might see a blank screen for up to 30 sec)
